Как добавить репозиторий
  • 01Открой Sileo, Cydia или Zebra на jailbroken устройстве
  • 02Перейди во вкладку Sources (Sileo) или Manage → Sources (Cydia)
  • 03Нажми Edit → Add (Cydia) или + (Sileo / Zebra)
  • 04Вставь URL: https://olegmmg.github.io/repo/
  • 05Нажми Add Source и дождись обновления индекса
