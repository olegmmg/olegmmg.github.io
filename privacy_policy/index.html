1. Общие условия

  • API предоставляется бесплатно для любых проектов.
  • API-ключ является персональным. Запрещена передача ключа третьим лицам, публикация в открытом доступе, вставка в публичные репозитории без шифрования.
  • Автор (далее — «Правообладатель») оставляет за собой право отозвать ключ в любой момент без объяснения причин.
  • Запрещено использовать API для деятельности, нарушающей законодательство РФ и международные нормы.
  • Запрещено распространение вредоносного ПО, спама, фишинговых ссылок с использованием данных API.

2. Ограничения по нагрузке

  • ❌ Запрещены DDoS-атаки и любые попытки вывести сервер из строя.
  • ❌ Запрещено заполнять сервер бесполезной нагрузкой: бессмысленные повторяющиеся запросы, запросы с неверными ключами в цикле, искусственное создание трафика.
  • ❌ Запрещён парсинг с частотой более 10 запросов в секунду.
  • ❌ Запрещено создание множества фейковых заявок на получение ключей.
  • ✅ Рекомендуется кешировать данные на клиенте и делать запросы не чаще чем раз в 30 секунд.

3. Атрибуция — ОБЯЗАТЕЛЬНОЕ УСЛОВИЕ

  • ❌ Запрещено скрывать, удалять, модифицировать или заменять подпись @olegmmg в поле message ответов API.
  • ✅ Если вы отображаете сообщения из поля message конечным пользователям (на сайте, в боте, в приложении), подпись @olegmmg должна оставаться видимой и неизменной.
  • ✅ Это касается всех производных продуктов: если ваш бот/сайт/приложение пересылает или показывает сообщение из API — подпись Правообладателя должна сохраняться.
  • ⚠️ Нарушение этого условия ведёт к немедленному отзыву ключа и блокировке доступа без предупреждения.

4. Требования к конечным приложениям

  • ✅ Конечные пользователи ваших приложений должны иметь возможность видеть подпись @olegmmg в сообщениях.
  • ✅ При ретрансляции данных (в Telegram-канале, на сайте, в приложении) вы обязаны сохранять подпись Правообладателя в каждом сообщении.
  • ❌ Запрещено создавать сервисы-прокладки, которые принимают запросы от третьих лиц и ретранслируют их к нашему API без добавленной ценности (простой прокси).
  • ❌ Запрещено перепродавать доступ к API или взимать плату за данные, полученные через наш API.

5. Последствия нарушений

  • Первое нарушение (некритичное) — предупреждение в Telegram.
  • Повторное или грубое нарушение — немедленный отзыв ключа без права восстановления.
  • IP-адрес нарушителя может быть заблокирован на уровне сервера.
  • При массовых DDoS-атаках информация может быть передана хостинг-провайдеру.

  • При подаче заявки собираются: email, Telegram-username, цель использования. Эти данные используются исключительно для рассмотрения заявки и связи с Пользователем.

  • Сервер не сохраняет IP-адреса запросов к API (кроме случаев автоматической защиты от DDoS).
  • Вы можете запросить удаление своих данных, написав Правообладателю в Telegram.
