💻 Готовый код

JavaScript

const API_KEY = "ВАШ_КЛЮЧ";
const SERVERS = [
  "https://radar-u913.onrender.com",
  "https://radar-twp9.onrender.com"
];

async function getStatuses() {
  for (const server of SERVERS) {
    try {
      const resp = await fetch(`${server}/api/statuses?api_key=${API_KEY}`);
      if (resp.ok) return await resp.json();
    } catch (e) {}
  }
  throw new Error("Все серверы недоступны");
}

// Использование:
const data = await getStatuses();
// data.regions["Белгородская область"].status → "missile_alert"

Python

import requests

API_KEY = "ВАШ_КЛЮЧ"
SERVERS = [
    "https://radar-u913.onrender.com",
    "https://radar-twp9.onrender.com"
]

def get_statuses():
    for server in SERVERS:
        try:
            resp = requests.get(f"{server}/api/statuses",
                              params={"api_key": API_KEY},
                              timeout=10)
            if resp.status_code == 200:
                return resp.json()
        except:
            continue
    raise Exception("Все серверы недоступны")

data = get_statuses()
# data["regions"]["Белгородская область"]["status"] → "missile_alert"

PHP

<?php
$API_KEY = "ВАШ_КЛЮЧ";
$SERVERS = [
  "https://radar-u913.onrender.com",
  "https://radar-twp9.onrender.com"
];

function getStatuses() {
  global $API_KEY, $SERVERS;
  foreach ($SERVERS as $server) {
    $url = $server . "/api/statuses?api_key=" . $API_KEY;
    $data = @file_get_contents($url);
    if ($data) return json_decode($data, true);
  }
  throw new Exception("Все серверы недоступны");
}

$data = getStatuses();
// $data["regions"]["Белгородская область"]["status"] → "missile_alert"

1. Общие условия использования

  • API предоставляется бесплатно для любых проектов — как некоммерческих, так и коммерческих.
  • API-ключ является персональным. Запрещена передача ключа третьим лицам, публикация в открытом доступе, вставка в публичные репозитории без шифрования.
  • Автор оставляет за собой право отозвать ключ в любой момент без объяснения причин.
  • Запрещено использовать API для деятельности, нарушающей законодательство РФ и международные нормы.

2. Ограничения по нагрузке

  • ❌ Запрещены DDoS-атаки и любые попытки вывести сервер из строя путём массовой отправки запросов.
  • ❌ Запрещено заполнять сервер бесполезной нагрузкой: бессмысленные повторяющиеся запросы, запросы с неверными ключами в цикле, искусственное создание трафика.
  • ❌ Запрещён парсинг с частотой более 10 запросов в секунду.
  • ❌ Запрещено создание множества фейковых заявок на получение ключей с целью заспамить систему.
  • ✅ Рекомендуется кешировать данные на клиенте и делать запросы не чаще чем раз в 30 секунд.
  • ✅ Рекомендуется использовать схему с fallback-сервером — это снижает нагрузку на основной сервер.

  • ❌ Запрещено скрывать, удалять, модифицировать или заменять подпись @olegmmg в поле message ответов API.
  • ✅ Если вы отображаете сообщения из поля message конечным пользователям (на сайте, в боте, в приложении), подпись @olegmmg должна оставаться видимой и неизменной.

  • ⚠️ Нарушение этого условия ведёт к немедленному отзыву ключа и блокировке доступа.

  • ✅ Ваши пользователи должны иметь возможность видеть источник данных — подпись @olegmmg в сообщениях.

5. Последствия нарушений

  • IP-адрес нарушителя может быть заблокирован на уровне сервера.
  • При массовых атаках информация может быть передана хостинг-провайдеру.
